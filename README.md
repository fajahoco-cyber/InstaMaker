# پست‌ساز (InstaMaker)

اپلیکیشن اندروید برای آماده‌کردن عکس پست و استوری اینستاگرام.
ساخته‌شده با Kotlin و Jetpack Compose.

## جریان کار

1. باز کردن برنامه، انتخاب اندازه (۱:۱ ، ۴:۵ ، ۹:۱۶) و انتخاب عکس: دوربین یا گالری
2. تب **قالب**: انتخاب قالب؛ با دکمه‌ی **+** قالب PNG خودتان را اضافه کنید
3. تب **متن**: تیتر و توضیحات دو متن جدا هستند و هرکدام فونت، اندازه، رنگ و عرض کادر خودشان را دارند
4. تب **عکس**: بزرگ‌نمایی، جابه‌جایی و تیره کردن عکس
5. **ادامه** ▸ پیش‌نمایش نهایی با اندازه‌ی واقعی خروجی
6. **ذخیره در گالری** (پوشه‌ی Pictures/InstaMaker) یا اشتراک‌گذاری مستقیم با اینستاگرام، واتساپ، تلگرام و بقیه‌ی برنامه‌ها

## جابه‌جایی آزاد متن

- روی تیتر یا توضیحات (داخل پیش‌نمایش) انگشت بگذارید و **هر جای بوم** بکشید.
- نزدیک وسط بوم متن به‌صورت خودکار می‌چسبد و خط راهنمای طلایی نشان داده می‌شود.
- با **دو انگشت** روی همان متن، اندازه‌اش را تغییر دهید.
- بیرون از متن کشیدن، عکس را جابه‌جا می‌کند و دو انگشت آن را بزرگ و کوچک می‌کند.
- اگر متن‌ها را دستی جابه‌جا کرده باشید، تغییر قالب یا اندازه جای آن‌ها را عوض نمی‌کند. دکمه‌ی «جای پیش‌فرض متن‌ها» آن‌ها را برمی‌گرداند.

## فونت

- فونت‌های داخلی: وزیرمتن در ۵ وزن (سبک، معمولی، متوسط، ضخیم، سیاه) و سه فونت سیستم.
- **فونت دلخواه:** تب متن ▸ «افزودن فونت» و انتخاب فایل `.ttf` یا `.otf`. فونت داخل برنامه ذخیره می‌شود و برای تیتر یا توضیحات قابل انتخاب است. برای حذف، روی آن نگه دارید.
- فونت وزیرمتن با مجوز SIL OFL همراه برنامه است (فایل `FONT-LICENSE-Vazirmatn-OFL.txt`).

## اجرا

1. Android Studio (نسخه‌ی Koala یا جدیدتر) را باز کنید
2. **File ▸ Open** و پوشه‌ی `InstaMaker` را انتخاب کنید
3. صبر کنید Gradle همگام شود (اولین بار SDK 34 را خودش دانلود می‌کند)
4. گوشی را با USB وصل کنید و دکمه‌ی **Run** را بزنید

برای ساخت APK با گیت‌هاب، فایل `.github/workflows/build.yml` آماده است: push کنید و از تب Actions ▸ Artifacts فایل APK را بگیرید.

حداقل نسخه‌ی اندروید: ۱۰ (API 29).

## قالب PNG

- فایل باید **PNG با پس‌زمینه‌ی شفاف** باشد (قاب، استیکر، لوگو، گرافیک و...). فایل بدون شفافیت رد می‌شود چون عکس را می‌پوشاند.
- بهترین اندازه‌ها: `1080×1080` ، `1080×1350` یا `1080×1920`.
- اگر نسبت قالب به یکی از این سه اندازه نزدیک باشد، اندازه‌ی خروجی خودکار همان انتخاب می‌شود.
- قالب‌های اضافه‌شده داخل برنامه ذخیره می‌شوند. برای حذف، روی آن‌ها نگه دارید.

## ساختار کد

| فایل | کار |
|---|---|
| `MainActivity.kt` | نقطه‌ی ورود و ناوبری |
| `Theme.kt` و `UiKit.kt` | رنگ‌ها، فونت رابط و اجزای ظاهری (دکمه‌های قرصی، کارت‌ها) |
| `HomeScreen.kt` | انتخاب اندازه و دوربین/گالری |
| `EditorScreen.kt` | پیش‌نمایش زنده، لمس و تب‌های قالب، متن و عکس |
| `FinalScreen.kt` | پیش‌نمایش نهایی، ذخیره و اشتراک |
| `PostRenderer.kt` | رسم عکس، قالب و متن (هم برای پیش‌نمایش، هم برای خروجی) |
| `FontStore.kt` | فونت‌های داخلی و فونت‌های کاربر |
| `EditorViewModel.kt` | وضعیت برنامه |
| `TemplateStore.kt` | نگه‌داری قالب‌های PNG کاربر |
| `Exporter.kt` | ذخیره در گالری و اشتراک‌گذاری |
| `Models.kt` | مدل‌ها و قالب‌های آماده |
